# Support Escalation Skill

Goal:
Determine whether technical issues create meaningful customer risk.

Procedure:
1. Review support summary.
2. Inspect ticket history when critical, unresolved, reopened, or recurring issues exist.
3. Distinguish historical resolved issues from active problems.
4. Escalate when severe or recurring technical issues materially affect customer experience.
5. Recommend remediation and ownership.

Completion criteria:
Return severity, recurring themes, evidence, and recommended actions.
